# User Flow

## Member

### Registrasi
1. Buka landing page merchant (misal: Golden Sport Fitness)
2. Pilih paket membership
3. Isi form pendaftaran (nama, no. HP, email)
4. Upload bukti pembayaran
5. Menunggu verifikasi admin
6. Terima konfirmasi — membership aktif

### Akses Member Dashboard
1. Login dengan akun
2. Lihat status membership (aktif, expired, paket)
3. Lihat riwayat check-in & aktivitas
4. Lihat merchant lain yang diikuti
5. Lihat promo & loyalty reward

### Check-in
1. Tunjukkan QR Code / ID member ke staff
2. Staff scan / input manual
3. Check-in tercatat di dashboard member & admin

---

## Staff / Kasir

1. Login ke dashboard merchant
2. Verifikasi pembayaran member (approve / reject bukti transfer)
3. Input check-in member manual
4. Lihat daftar member aktif hari ini

---

## Merchant Admin

1. Login ke dashboard merchant
2. Kelola paket membership (tambah, edit, nonaktifkan)
3. Kelola daftar member (aktif, expired, pending)
4. Verifikasi pembayaran
5. Lihat statistik — member aktif, revenue, check-in
6. Kirim promo / notifikasi ke member (future)

---

## Super Admin (PT. Satria GS)

1. Login ke dashboard pusat
2. Lihat overview semua merchant
3. Lihat data member lintas merchant
4. Identifikasi member baru / loyal / cross-merchant
5. Kelola program loyalti & promo
6. Lihat laporan keuangan lintas merchant
